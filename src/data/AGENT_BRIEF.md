# 공통 지시 (캐릭터 데이터 수집 에이전트)

목표: 어나더 에덴 캐릭터 데이터를 `/home/claude/aeopt/data/SCHEMA.md` 스키마대로 JSON 배열로 작성해 지정된 파일에 저장한다.

## 정보원 (우선순위)
1. altema 캐릭터 페이지: `https://altema.jp/anaden/chara/<ID>` — WebFetch로 읽고 "スキル一覧 전문, アビリティ, ヴァリアブルチャント, 星導スキル/星導アビリティ, 顕現武器 강화 내용"을 요청. 한 번에 안 나오면 프롬프트를 바꿔 2회까지 재시도.
2. 보조: anothereden.wiki (영문, `https://anothereden.wiki/w/<Name>`) 또는 altema 최강랭킹(`https://altema.jp/anaden/sikyo`)의 성능 요약.
3. 한국어 이름: 아래 매핑표 우선. 없으면 `thewiki.kr` 또는 나무위키 검색으로 확인. 끝내 못 찾으면 자연스러운 한국어 음차를 쓰고 note_kr 끝에 "(한국어명 미확인)" 표기.

## 수치 해석 규칙
- 위력 표기 "威力N倍" → mult=N. 크기(小/中/大/特大/極大) → size s/m/l/xl/xxl. 표기 없으면 mult=1.
- "再攻撃"/"再度攻撃"/"再行動" → repeat = 추가 횟수 (1회 재공격이면 1). 조건은 condition에.
- 버프 수치는 스킬/VC/어빌리티로 **자기 자신이 낼 수 있는 최대치**. 누적(累積) 버프는 최대 누적값.
- 디버프도 최대치. "全属性耐性" → all_elem_res, "物理耐性" → phys_res, "魔法耐性" → mag_res, "斬/打/突耐性" → weapon_res.
- ZONE 전개 가능하면 zone 채움. 極·絶 ZONE 가능하면 awakened=true.
- 서포트 등급: heal(회복) barrier(배리어/실드/피해경감) cleanse(상태이상/디버프 해제) guard(수호/비호/守勢·庇立て) taunt(도발) mp_recover af_gauge status_immune 를 0~3으로.
- roles: 주력 딜이면 dps, 전체 버프/디버프가 주 역할이면 support/debuffer, 회복 전담 healer, 탱 tank, 존 전개 zone, 브레이크 breaker.
- tier/score는 altema 최강랭킹·평가점 그대로. 랭킹표에 없으면 tier "".

## 출력
- 반드시 유효한 JSON 배열 하나만 파일에 저장 (주석 금지). 저장 후 `python3 -I -c "import json;json.load(open('<파일>'))"`로 검증.
- 완료 보고는 "저장 파일 경로, 캐릭터 수, 한국어명 미확인 목록, 수치 불확실 캐릭터" 만 짧게.
